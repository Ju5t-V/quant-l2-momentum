# quant-l2-momentum

Scaffold for a **Level-2 / Level-3 order-book momentum** trading framework in Python.

- `qlm/core/`: order-book (`book.py`, `l3book.py`) and event model
- Module skeletons for feeds, features, strategies, execution, portfolio, backtest, recording and alerts
- `pine/`: companion TradingView scripts

## Status
🔴 Early stage. The core order-book data structures are in place, and the other modules are stubs.

> ⚠️ Research and educational code only. Not financial advice. Backtests are not a promise of future results.
